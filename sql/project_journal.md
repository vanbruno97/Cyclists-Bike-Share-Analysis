# Project Journal

**Project:** Cyclistic Bike Share Analysis

**Author:** Ludwig Van Bruno Bagnolok

**Tools:** SQL (BigQuery), Tableau Public, Excel, Python (coming soon)

---

# Phase 1 — Ask

## Business Task

The marketing team wants to increase the number of annual memberships by understanding the behavioral differences between annual members and casual riders.

### Business Questions

1. How do annual members and casual riders use Cyclistic bikes differently?
2. Why would casual riders buy annual memberships?
3. How can Cyclistic use digital media to convert casual riders into members?

---

# Phase 2 — Prepare

## Data Source

The analysis uses the Cyclistic trip dataset provided in the Google Data Analytics Capstone.

### Actions Completed

- Imported the twelve monthly datasets into Google BigQuery.
- Verified that every monthly table shared the same schema.
- Merged the datasets into a single table.

---

# Phase 3 — Process

## Data Cleaning

Performed the following quality checks:

- Checked missing values.
- Verified duplicate ride IDs.
- Identified negative ride durations.
- Verified coordinate consistency.

## Feature Engineering

Created the following variables:

- ride_length_minutes
- day_of_week
- day_name
- month
- hour

These variables were used to support behavioral analysis.

---

# Phase 4 — Analyze

Performed descriptive analyses including:

- Rider distribution
- Average ride duration
- Weekly usage
- Monthly usage
- Hourly usage
- Bike type preferences

---

# Phase 5 — Share

Created an interactive dashboard using Tableau Public.

The dashboard includes:

- Rider Distribution
- Ride Duration
- Weekly Usage
- Monthly Usage
- Hourly Usage
- Bike Type Preference

---

# Phase 6 — Act

Based on the analysis, business recommendations were proposed to encourage casual riders to purchase annual memberships.

---

# Project Outcome

The project successfully answered the three business questions and demonstrated a complete analytical workflow from raw data to business recommendations.
