# Excel Analysis

## Objective

Reproduce the SQL analysis using Microsoft Excel.

## Tasks Completed

- Imported the cleaned dataset from BigQuery.
- Calculated descriptive statistics.
- Created Pivot Tables.
- Built simple charts to summarize the results.

## Key Findings

- Average ride length: **13.78 minutes**
- Maximum ride length: **1499 minutes**
- Casual riders have longer rides than members.
- Weekly riding patterns are consistent with the SQL analysis.

## Conclusion

The Excel analysis confirms the findings obtained with SQL and demonstrates proficiency with spreadsheet-based data analysis.
